# Crestwood Music School

Standalone static website for Crestwood Music School.

## Files

- `index.html` — music school homepage
- `css/site.css` — website styles
- `images/` — Crestwood logo, music-school poster, instrument photos and
  converted PNG copies of the HEIC photos
- `images/thumbnails/` — lightweight WebP previews for the photo gallery
- `sitemap.xml` and `robots.txt` — search engine files

## Publish this folder as its own GitHub Pages site

To publish independently from Crestwood Play & Care, create a separate GitHub
repository for the music school and copy the **contents of this folder** into
the repository root. Enable GitHub Pages under **Settings → Pages**.

The canonical URL, social preview URLs, structured data and sitemap currently
assume this site is published at
`https://crestwoodplay.com/crestwood%20music%20school/`. If the site is
published at a different URL or domain, update those URLs in `index.html`,
`sitemap.xml` and `robots.txt` before launch.

The inquiry form prepares a message in WhatsApp for +91 95403 80569.

## Search visibility

The homepage includes local music-school and course information, structured
data, and a sitemap. After publishing at the final URL, verify that URL in
Google Search Console and submit this folder's `sitemap.xml`. Keep the site's
name, address, phone numbers and hours consistent with the school's Google
Business Profile. Add the website URL to that profile and request genuine
reviews from students and parents; search placement cannot be guaranteed by
website changes alone.
